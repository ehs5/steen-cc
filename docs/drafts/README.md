# Drafts

Approved visual references for Designs. Each Design must match its Draft visually: layout, type, sizes, colours, borders, shadows and hover effects. It only differs where the Content differs.

| Draft | Design | Files |
| --- | --- | --- |
| Neo-brutal Pop | `pop` | `neo-pop.html`, `neo-pop-1280.png`, `neo-pop-375.png` |
| Footnotes | `footnotes` | `footnotes.html`, `footnotes-1280.png`, `footnotes-375.png` |

The HTML files are standalone; open them in a browser. They load Google Fonts only for preview, and the built Designs self-host their fonts.

The Drafts were made with older Content (a tagline, a skills list, older project names and descriptions). Port the styles, not the copy: the Content always comes from the Content module and the About text.
